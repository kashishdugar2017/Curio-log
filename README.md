# Curio Log

Curio Log is a fun web application built with **Django** designed to help curious learners organize their thoughts, track new ideas, and document everything they discover. 

## Features
* **Topic Organization:** Categorize different things you learn by subject or interest.
* **Idea Logging:** Quickly jot down new thoughts or questions you want to research later.
* **Simple & Fun UI:** Designed to make the process of keeping track of your learning journey easy and enjoyable.

## Built With
* Python
* Django (Web Framework)
* HTML / CSS
